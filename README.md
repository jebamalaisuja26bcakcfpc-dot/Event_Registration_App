🎟️ Event Registration App

A modern Event Registration Mobile App UI/UX design created in
Figma.
The application provides a smooth experience for discovering events,
viewing event details, registering for events, and tracking
registrations.

✨ Project Preview

This project focuses on a premium dark navy + purple + gold visual
style, designed to give the event platform a modern and elegant
appearance.

🎨 Design Theme

🌌 Dark Navy background

💜 Purple gradients and highlights

✨ Gold accent color

🟣 Rounded cards and buttons

📱 Mobile-first UI

🎯 Clean and easy navigation

🎯 Objective

The main objective of this project is to design a simple and visually
engaging platform where users can:

Discover → Explore → Register → Participate

in events through a single mobile application.
